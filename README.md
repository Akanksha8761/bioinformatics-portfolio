### 👋 About Me

I'm a Bioinformatics Analyst with experience spanning clinical NGS variant analysis, deep learning applications in genomics, and multi-omics data integration. I currently work at **MedGenome Labs, Bengaluru**, where I perform clinical variant confirmation across germline, somatic, haematology, WGS, and RNA-seq NGS panels, validate new sequencing pipelines, and build automation tooling that replaces manual bioinformatics workflows.

Before this, as a Project Associate - I at **CSIR-IHBT**, I built and deployed deep-learning-powered bioinformatics web servers, ran bulk and single-cell RNA-seq / WGBS analyses, and co-authored peer-reviewed work on multi-omics gene regulatory network inference.

I hold an M.Sc. in Human Genomics and a B.Sc. (Hons) in Bioinformatics, both from Panjab University. I'm currently working toward more senior clinical/genomics bioinformatics roles, with a focus on pipeline architecture, complex variant classes (CNVs, fusions, MRD), and scalable clinical genomics infrastructure.
